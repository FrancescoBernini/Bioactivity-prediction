# bioactivity-prediction
Machine learning models for predicting the bioactivity of plant-derived molecules. Final project for the AI Laboratory course.

# Obiettivo
L'obiettivo è predire la bioattvità delle molecole a partire da tutte le altre informazioni che trovi nel dataset.
La bioattività è riportata, come dice il readme, nella colonna "bioattività --> "Activity_ID"
